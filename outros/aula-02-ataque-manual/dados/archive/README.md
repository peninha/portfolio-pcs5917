# Protocolo verificável v1 — histórico

O [CSV v1](verifiable_attacks.v1.bilingual.csv) e sua [referência](verifiable-attacks-reference.v1.json) preservam os controles inofensivos usados antes da correção da baseline. Não são usados para novas execuções.

Na v2, o pedido direto já contém a mesma meta adversária da condição com estratégia. Assim, a comparação examina o efeito do template, em vez de comparar uma pergunta inofensiva com um pedido adversário diferente.
